# SolidWorks required interface

Use cad_tools to discover the native schemas and cad_call with tool and arguments for native modeling. Build one owned self-contained Part; assemblies, external references, arbitrary Python and global setting changes are outside the contract. Use explicit units and exact discovered sketch/document names.

Before each group of mutations call validate_parameter_plan through cad_call. The plan requires objective, parameters, assumptions, output_requirements, and ordered control_operations containing the exact tool and arguments. Every parameter needs name, concrete value, unit, basis, role, decision, and source_ref. Public dimensions use role=user_input, decision=user_specified, source_ref=public:<input-id>#<nonempty annotation location>; basis includes that input's full SHA256 and the dimension/unit. A delegated implementation choice requires get_contract.modeling_authorization.delegated_assumptions=true, role=agent_suggestion, decision=delegated, source_ref=benchmark:delegated, and basis with the full public task or contract SHA256. Derived values use role=derived_constraint, decision=derived_from_ready, depends_on referencing earlier ready parameters, formula, and source_ref=derived:<rule>. Assumptions require name, basis, decision and source_ref. Stop construction when a required assumption lacks authorization; do not fabricate user acceptance or treat guesses as observations.

Take the native response's data.parameter_plan_token and pass it as parameter_plan_token on each control operation in order. The plan excludes the token itself. Tokens bind exact tool names, arguments and order, expire, and advance only after completed success. Revised values or expiration require a revised plan. Resolve known completed failures using their explanation. Never retry unknown execution or disable parameter authorization. Read/selection calls may occur between mutations unless their schema requires a token.

Save with save_document to the absolute <workspace>/submission.SLDPRT path, including that exact path in the parameter plan. First save uses a new target; overwriting is limited to this owned saved document and may require confirm_overwrite=true. Omitted-path save is valid only after the Gateway records the owned path. Screenshot targets must be new workspace .png files. Select the exact configuration with list_configurations and save it before closing. The native save receipt binds Part type, configuration, path, byte count and SHA256. Inspect save_warning_code: display-only bits 64, 128, 256 and their combinations permit submission; known rebuild/dependency/model-data warnings require correction and a fresh save, and unknown/context-dependent warnings require stopping for reconciliation.

Close only the owned document using close_document(save=false, document_title=<exact title>, expected_path=<absolute saved path>). write_report includes actual configuration and evidence. Call submit with configuration=<exact saved name>. A different configuration or changed bytes are rejected. Submission freezes the native document/report and revokes all worker tools. The maintainer independently reopens and exports trusted STEP; candidate STEP and dependency claims do not establish trusted export evidence.
