# Optional SolidWorks modeling advice

Read orthographic views together before choosing a base feature. Identify shared axes, symmetry and repeated features; use those relationships to choose a compact feature sequence.

Inspect feature health, bodies and configurations through allowed native tools before saving. Check continuity and the dimensions most likely to expose a mistaken interpretation of the drawing. Record measured observations separately from visual impressions.

When a known completed operation fails, inspect the stated precondition and revise the intended construction before making a new parameter plan. A simple sketch or feature can help localize a geometric problem.
