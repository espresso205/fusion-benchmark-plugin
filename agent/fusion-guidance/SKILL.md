# Optional Fusion modeling advice

Combine all drawing views when identifying the base shape, symmetric structure and repeated features. Prefer a feature sequence whose named dimensions correspond clearly to the annotations.

Keep execute scripts short enough to inspect their results. Construct geometry with native sketches, features and BRep APIs; inspect solids and feature health incrementally. A rendered image alone does not prove solid validity.

Inspect body count, actual dimensions and feature warnings before exporting, and report measured values and remaining limitations. The checks should follow the drawing's most consequential requirements.
