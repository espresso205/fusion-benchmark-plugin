# 2026-10-28 报告交互与 CAD 流程修订

本次修订解决报告布局和交互状态不一致、差异着色难以辨认，以及 CAD 完成状态分类过宽的问题。基线为 `bf5c4789162f3b193335ca954c37631d082000f9`。修改限于显示、流程分类、测试和文档；评分算法、权重与既有测量证据不变。

## 报告

- 固定 `comparison-first-v2` 模板，所有报告入口共用生成器。列表只显示题目身份与模型缩略图；单题按三维对比、四视图、结果和结论、折叠资料排列。
- 进入题目和重置时恢复一致的坐标、视角、显示方式、透明度及资料状态；切换坐标保留检查位置，避免异步初始化覆盖用户选择。
- 四视图 PNG 提升为 2560×960，独立生成并排、透明叠加、差异着色三套资产。放大窗口支持缩放、拖动、适应窗口和 1:1；同角度切换比较方式保留缩放和平移。
- 默认差异采用显示网格精度内的表面容差，分离匹配、多余、缺失图层，减少极薄布尔片层造成的混色和条纹。容差明确披露，不参与评分；精确体积差异保留原始布尔层供内部差异检查。
- 结果区区分直径偏差、曲面数量差异和未检出特征，圆锥明确显示半角；面分割数量不能直接解释成孔数。
- 修复嵌入 Python 下显示 worker 的平级模块导入，保持从当前源码位置启动。

界面合同和显示限制见 [HTML_REPORT.md](HTML_REPORT.md)。

## CAD 流程

1. 可靠的未修改输入拒绝不再升级为 CAD 状态未知。判定仍严格绑定已审查的供应方源码、请求和进程证据。
2. 派发前工作区检查失败不再增加未决建模请求；已派发未知操作继续阻断。维护探针传输未知会持久化，不能靠重启绕过。
3. 零 CAD 调用且正常退出未提交的候选，在进程、桌面和输入身份重新确认后记录为缺失提交，不生成分数、不误阻断后续题目。

完整边界见 [CAD_BACKENDS.md](CAD_BACKENDS.md)。本次没有自动重复原生建模写操作的功能。

## 验证

源码测试使用合成输入与 CAD/CLI 边界替身，没有重新调用候选模型或重跑本批 CAD 建模。几何测试使用既有 OCP/VTK 运行时；浏览器测试使用 Playwright 和 Edge。

- Python 全套（开启 `RUN_GEOMETRY_TESTS=1`）：673 项，4 项因未配置可选供应方资产或历史回归数据而跳过。
- Node 全套：51 项，包含 Gateway guard、viewer 和真实浏览器交互回归，无跳过。
- 本地十题报告逐题验证两套坐标、真实网格、旋转缩放、显示方式、四视图、资料和下载；补充桌面及窄屏放大窗口检查。
- 历史报告、成绩和冻结安装包完整性独立校验；报告及私有模型不进入源码仓库。

复现源码检查：

```powershell
$env:RUN_GEOMETRY_TESTS = '1'
python -B -m unittest discover -s tests -v
node --test tests/fusion_guard.test.mjs tests/report_state.browser.test.cjs tests/viewer.test.mjs
```

浏览器测试需要可用的 Playwright 和浏览器；可通过 `REPORT_TEST_PLAYWRIGHT` 指定模块路径、`VIEWER_TEST_BROWSER` 指定浏览器。缺少这些依赖时相关测试会跳过，不能把跳过当作浏览器验收通过。

## 源码身份与范围

本次同步 `SCORING_SOURCE_MANIFEST.json` 中 11 个已审查的流程和显示文件及 viewer 来源清单，保留每个文件的上一版 SHA256，并记录修改原因。`VIEWER_SOURCES.json` 同步本地适配代码摘要，保留原上游身份。评分核心与权重摘要不变。该清单更新描述当前源码身份，不追溯改写历史运行身份。

此次交付是源码提交；没有构建或发布新的便携包，也未替换本机 MCP 所指冻结安装包。便携发布仍须按 [BUILD.md](BUILD.md) 单独构建、移位与验证。

## 后续必须处理的准入问题

- 在候选派发前增加工程图关键尺寸与技术要求的可读性审查；能解码图片不代表工程信息完整。审核须绑定输入哈希，修复输入应形成新数据版本。
- 在候选派发前验证 GT 的全部主指标可测性，包含评分网格闭合及拓扑路径；健康 BRep 不保证评分网格有效。GT 缺测不能解释成候选零分。

上述两项已完成审计，尚未实现。圆柱探针对 BRep 面分割敏感的问题需另立评分版本解决；不能删除计数检查后追溯修改成绩。人工恢复回执和多 run 报告合成也仍需正式工具支持。
