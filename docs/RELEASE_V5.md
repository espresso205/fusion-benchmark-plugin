# v5.0.0-assembly.1 发布说明

此次发布把经过验证的v5装配评测接入完整benchmark插件。默认协议仍为v4；选择v5后，装配检查和相似度测量分开，阶段超时保留其他可测结果，未验收参考不能发布完整总分。详细对照见[v5与v4](V5_V4_COMPARISON.md)。

## 包含的变化

- v5评测入口、结果规则、物理零件识别与匹配、有限区域配合许可、分阶段运行和质量计算。
- 管理入口、评测快照、验收身份、结果核验和静态报告同步支持v5。
- 更新包先核对基线文件再备份替换；操作日志在修改前持久化，可从安装或恢复中断继续恢复。
- 保留现有CLI档案、推理设置、skills/MCP能力选择与离线能力实验功能，并将其所需的源文件和测试一起发布。

本发布整合的v5评测与管理代码来自独立评测器工作副本提交 `e2d338049722d64e35f1d82e8d1c5519b2e2ac92`。插件集成调整了测试加载路径、文档及发布清单；具体身份以本仓库 `SCORING_SOURCE_MANIFEST.json` 为准。

## 下载和选择

完整Windows x64便携包自带Python和依赖，解压后按[使用说明](PORTABLE_PLUGIN_USAGE.md)配置。已有2026-10-29 smokeprompt基线安装可使用配套更新包；其他版本使用完整包，或从本仓库安装源码。更新包不携带GT、候选或运行成绩。

旧安装更新工具在 `scripts/assembly_update/`。更新包拒绝覆盖与预期基线不一致的文件；恢复方法随包附带。v4入口与历史输出保持原义。

## 验证与边界

本次发布重新运行完整插件Python测试和Node测试，并从发布内容核对全部评分源码和包文件指纹。具体测试数量和结果随GitHub release及发布验收记录提供。合成几何检验不启动真实模型或Fusion。

此前集成验证已覆盖完整插件副本安装、恢复、再安装，以及v4/v5盒体和v5真实装配输入。发布不包含私有题目、参考或它们的结果。插件能够运行不代表任何GT自动完成工程验收，几何高分不等于装配合格。
