# 装配评测更新包

本包把明确选择的新评测规则安装到现有插件。原有 v4 入口和历史结果继续保留。运行时、第三方库和许可证沿用现有安装，本包不包含题目或参考答案。

安装前结束正在运行的评测。解压后在 PowerShell 执行：

```powershell
.\install.ps1 -PluginDirectory 'C:\tools\fusion-benchmark-cli-capabilities-smokeprompt-20261029'
```

安装器先核对所有待替换文件，再在插件旁创建备份。原文件与更新包的基线不一致时停止，不覆盖本地改动。安装成功会打印备份目录。

安装后重新加载插件或重启使用该插件的客户端，使管理入口载入新版。这个更新包适用于目录名为 `fusion-benchmark-cli-capabilities-smokeprompt-20261029` 的已核验基线；安装器会用文件内容核对版本。

新评测使用 `fusion-step-adapted-v5.0`。直接运行：

```powershell
& '<插件目录>\runtime\python\python.exe' -X utf8 -B '<插件目录>\evaluate.py' --protocol fusion-step-adapted-v5.0 --cases '<绝对路径>\cases.json' --output '<不存在的新结果目录>' --timeout 600 --stage-timeout 90 --workers 4
```

完整分数只用于参考已验收、基础几何通过、三项测量齐全的题。参考验收文件及其哈希必须写进题目清单。没有验收文件时仍保留测量结果，但不发布正式分数。配合规则见 `docs/SCORING_V5.md`。自动建模流程的配置也需明确选择该协议。

恢复时使用安装器打印的真实备份目录：

```powershell
.\install.ps1 -PluginDirectory '<插件目录>' -RollbackBackup '<安装时生成的备份目录>'
```

恢复会核对更新后的文件是否被再次修改，再恢复原文件并收回本次新增文件。历史输入、候选、成绩不受影响。也可以继续明确选择 `fusion-step-adapted-v4.0` 重现旧规则。

如果安装或恢复被中断，保留插件旁的备份目录，使用同一条恢复命令继续。恢复完成后可以再次安装。备份内的 `restore.json` 记录操作进度，不能手工修改。
